# multtt

Плеер 2D-мультиков для вертикальных видео (1080×1920, TikTok) про строителей и инженеров. Сцены, локации и графика задаются в JSON, а слова лежат отдельно по языкам. Один и тот же мультик можно выпускать на разных языках.

Герои: **Инженер** (`eng`, очки) и **Строитель** (`bld`, каска и жилет). У них нет лиц, только рот и брови, а брови появляются лишь вместе с эмоцией.

## Запуск

Нужен только браузер (лучше Chrome). Из-за загрузки файлов открывать через маленький сервер:

```
python3 -m http.server 8000
```

и открыть `http://localhost:8000`. Либо включите GitHub Pages для репозитория (Settings → Pages → ветка `main`) и открывайте страницу по ссылке.

Если открыть `index.html` двойным кликом, автозагрузка не сработает, но можно перетащить файлы `scene / lang / library .json` на страницу или нажать «Открыть файлы…».

## Как это устроено

| Файл | Что внутри |
|---|---|
| `index.html` | плеер: просмотр, перемотка, проверка JSON, запись в `.webm` |
| `engine.js` | движок: герои, позы, эмоции, камера, эффекты, рисование фигур из JSON |
| `library.json` | общая библиотека локаций и предметов |
| `scenes/*.json` | сцены: тайминги и действия, **без слов** |
| `lang/*.json` | тексты сцены на конкретном языке: реплики, титры, вывески |
| `manifest.json` | список сцен и их языков для выпадающих списков |
| `docs/ai1_scenarist.md` | инструкция для ИИ, который пишет сценарий |
| `docs/ai2_animator.md` | инструкция для ИИ, который пишет JSON сцены |

## Рабочий процесс

1. **ИИ-1** пишет сценарий по `docs/ai1_scenarist.md`: действия отдельно, реплики таблицей с id и временем озвучки.
2. Сценарий вместе с `docs/ai2_animator.md` отдаёте **ИИ-2**, он возвращает JSON сцены. Если нужна новая локация или предмет, он рисует их в `defs` прямо в сцене.
3. Вставляете JSON во вкладку «Сцена», тексты (из сценария) во вкладку «Тексты», нажимаете **Применить** (или Ctrl+Enter). Вкладка «Проверка» покажет ошибки, которые можно сразу вернуть ИИ.
4. Когда сцена нравится, новые `defs` переносите в `library.json`, а сцену и тексты кладёте в `scenes/` и `lang/` и добавляете в `manifest.json`.
5. Кнопка **● Запись** проигрывает сцену и сохраняет `.webm` (или записывайте экран через OBS). Озвучку и титры можно накладывать в видеоредакторе. Субтитры в самом плеере можно отключить галочкой.

Для другого языка: переведите файл `lang/…` с теми же id, положите рядом и добавьте в `manifest.json`. Сцена не меняется.

## Тайминги

Сцена подгоняется под озвучку, а не наоборот. Надёжнее всего сначала записать голос и по нему задать `dur` каждой реплики. Плеер сравнивает длину текста со слотом (знаков в секунду берётся из поля `cps` файла языка: русский ≈ 14, английский ≈ 15) и подсвечивает реплики, которые не влезают. Оценка приблизительная: она нужна, чтобы поймать явные перекосы до озвучки.

## Ограничения версии 0.1

- Два героя, набор поз и эмоций фиксирован (20 поз, 12 эмоций). Новые позы добавляются в `engine.js`.
- Рисование только 2D-фигурами и SVG-путями.
- Запись `.webm` идёт в реальном времени. Звука в записи нет.
