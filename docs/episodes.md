# Эпизод: склейка сцен (episode.html)
Страница `episode.html` («Эпизод →» в студии) проигрывает несколько сцен подряд как один ролик, умеет обрезать сцены, вырезать куски внутри сцены, переключать язык и записывать всё в один `.webm`. Видео не склеивается: кадр каждый раз строится из JSON по времени, поэтому вырезы бесплатны.

## Файлы
- `episodes/index.json` — список эпизодов: `{"episodes":[{"id","title","file"}]}`.
- `episodes/<id>.json` — сам эпизод:
```json
{"id":"story_11","title":"…","lang":"ru","fade":0.25,
 "scenes":[
   "story_11_s01",
   {"scene":"story_11_s02","in":1.0,"out":14.5,"cuts":[[4.0,6.5],[9,10]]},
   "story_11_s03"
 ]}
```
- `scene` — id из `manifest.json`; строка вместо объекта = вся сцена целиком.
- `in` / `out` — начало и конец, секунды сцены (по умолчанию 0 и вся длина).
- `cuts` — вырезаемые куски, секунды сцены. Состояние сцены (предметы, камера) при вырезе остаётся правильным: кадр после выреза считается заново с нуля.
- `fade` — затемнение на стыках разных сцен, секунды (0 или не указывать — резкий стык).
- `lang` — язык по умолчанию. Если у сцены такого языка нет, берётся её первый, и в проверке появится предупреждение.

## Как пользоваться
**Горячие клавиши** (курсор ставишь на нужной секунде на таймлайне или стрелками; правка сразу пишется в JSON справа):
`I` начало сцены · `O` конец сцены · `[` начало выреза · `]` конец выреза · `X` сбросить правки текущей сцены · `Backspace` или `Ctrl+Z` отмена · `Esc` отменить начатый вырез · `←` `→` шаг 0,1 с (`Shift` — 1 с, `Alt` — 1 кадр) · `↑` `↓` прошлая/следующая сцена · `Пробел` пауза · `Home` `End`. Работают и на русской раскладке (Ш, Щ, Х, Ъ, Ч).
Результат остаётся в тексте справа: «Скачать»/«Копировать» и отдать на коммит в `episodes/`.
Можно и править JSON руками и нажать «Применить». На таймлайне цветные блоки — сцены, жёлтая отметка — место выреза. Таблица кусков кликабельна. «Запись эпизода» пишет весь ролик в реальном времени (Chrome), файл называется `<id>_<язык>.webm`. Для записи 1080×1920 выбери «Полное» качество.

## Ограничения (пока)
Нет звуковой дорожки. Реплики без `dur` пересчитываются под язык, но остальные действия стоят на фиксированных секундах.
