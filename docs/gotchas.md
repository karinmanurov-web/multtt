# Ловушки движка (выучено на практике)
- `pose` с `dur` через это время сам возвращается в `idle`. Для лежания/сидения/удержания позы `dur` не указывай.
- `place`/`walk`: `y` — смещение вверх (минус), а не мировая координата. У `spawn` и `move` предметов `y` — мировая.
- Предмет с тем же `id` после `remove` повторно не появится. Для повторного появления бери новый `id`.
- `move scale` на только что созданном предмете с `scale:0.01` бывает не работает — создавай сразу с итоговым масштабом.
- Только равномерный масштаб предметов (одно число). Для разной длины делай отдельные варианты реквизита.
- Слои: `back` рисуется под героями, `front` над ними. Предмет в руке — `front`.
- Камера zoom≥1 прижимается к границам мира (центр по y в [hh, H−hh]); чтобы показать подвал или крышу, используй zoom<1 (0.6–0.95).
- Портрет (`portrait`) к краю прижимается; у статистов (в т.ч. `arch`) только боковой ракурс, без `angle:"q45"`.
- Очень быстрый `walk` (>~1000 px/с) даёт предупреждение; для мгновенного перемещения — `place`.
- Эффекты на поднятых героях: `fx` с `x`,`y`, а не `who`.
- Новые числовые ключи позы должны быть в BASE, иначе смешивание поз их не интерполирует.
- Анимации предметов: `sway bob pulse spin fall shake drift slide blink`. Повороты у предметов (`rot`) — в градусах.
- Браузер кэширует `engine.js`: после правок повысь `?v=` в `index.html`, пользователю напомни Ctrl+F5.
- Деплой Pages иногда падает «Found 0 artifact(s)» (сбой GitHub): перезапустить `gh workflow run static.yml --ref main`.
